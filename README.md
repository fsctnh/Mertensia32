# Mertensia32

![alt text](https://github.com/fsctnh/Mertensia32/blob/260b1adb204e24101faeb97b6308a401522a7cd8/MainLogo.png)

## A Bluetooth compatible STM32WB55CEU6 dev-board.

### Contains:
* USB-C Connectivity
* Programmable STM32 based microcontroller
* SWD TAGCONNECT connector for ST-Link and other simmilar tools
* RF Antenna Slot
* Bluetooth capabilities
* UART Connector
* Low Voltage Design
* Compact form-factor

My first PCB with more than 2 layers! Special thanks to Philip Salmony (Phil's Lab) for the KiCad tutorials.

Future updates checklist:
* Exposing pins
* Improving via placement

**_This is an amateur board. Although frabrication files are available, do it at your own discretion._**
